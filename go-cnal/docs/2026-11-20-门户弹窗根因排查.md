# 门户弹窗根因排查（2026-11-20 晚，双通道上线当晚收口）

## 现象

Edge 反复弹出 a.stu.edu.cn 登录页。用户视角「莫名弹出」，有时 Edge 关着也弹新窗口（11-20
18:41、19:45:34 两次目击，watcher 实证）。Edge 历史显示根门户页访问长期高频：
11-08 62 次、11-19 40 次、11-20（至 19:45）52 次——不是偶发，是每小时 1-14 次的背景轰击。

## 排查路径（按否证链）

1. FlClash 主程序 → 否证（退出后仍弹；后续发现 FlClashHelperService 空壳存活但无 TUN 网卡）。
2. NCSI 主动探测 4038 → 否证（EnableActiveProbing=0 后静默但弹窗持续）。
3. Edge 自带门户探测（edge-http generate_204 返 429，chromium 非 redirect 不判 portal）→ 否证。
4. Windows「登录以连接」toast 链 → 否证（用户确认无任何 toast，浏览器直接弹）。
5. 守护切账号误伤 → 否证（19:34/19:41/19:45 三条门户 logout 记录在守护日志无对应动作，
   且 19:41:36 时旧守护已死 7 秒；用户确认当时未做任何门户操作）。
6. EdgeUpdate 计划任务 → 否证（本机无此任务；19:40-19:47 窗口无计划任务运行）。

## 决定性证据（19:45:34 复发全程被 watcher 抓到）

```
19:45:34 NEW msedge pid=24960 parent=38728(已退出) cmd="msedge.exe --single-argument https://a.stu.edu.cn/"
```

- `--single-argument <url>` = 系统层 ShellExecute 拉起默认浏览器，发起者短命中转即退。
- Edge 历史（UTC+8）同秒重放完整跳转链：根页 → index.htm → needauth.html → 登录表单，
  即**门户侧判定「未认证」后给出的流程页**。
- 弹窗时主链路（有线 10.141.53.34）实测在线（19:47:23 新守护起步即在线、无重登动作）、
  WiFi 通道探测已认证、Get-NetConnectionProfile 双接口 Internet。
- 用户 Edge 里残留的门户标签页 JS 在会话被踢后自动渲染 logout/needauth 链（历史里带
  username 的三条 logout，非用户操作）。

## 根因

**WiFi 会话无人维护 → 接口门户态 → Windows 门户检测自动拉浏览器。** 旧版守护 channels
为空，只维护有线主链路；WiFi（WLAN 2，172.29.153.208）的认证会话被踢/过期后，该接口
HTTP 流量被门户重定向（needauth 特征）。Windows 网络组件检测到该特征后 ShellExecute
门户 URL（无需 toast）。Edge 在跑时 = 进程内开新标签（白天的背景轰击，多数不显眼）；
Edge 全退时 = 起独立实例弹窗（18:41/19:45:34 的醒目弹窗）。会话被踢是第一因，
logout/needauth/弹窗全是下游。

## 对照验证（Edge 历史按小时 × 守护状态）

| 时段（11-20 本地） | 根门户页访问 | 环境 |
|---|---|---|
| 10:00-16:00 | 每小时 1-14 次 | 旧版守护在跑，channels 空（WiFi 无人维护） |
| 16:00-19:45 | 0 次 | 15:24 守护切账号 23jszeng，会话健壮期 |
| 19:41-19:45 | 5 次（弹窗簇） | 19:41:29 旧守护退出 → 门户 logout/needauth 链 |
| 19:47 之后 | 0 次 | 新守护上线，WiFi 通道首次纳入维护 |

## 解药与观察判据

新守护（1bf8b65 构建，19:47:22 上线）双通道持续维护 WiFi 会话 → 门户特征不再长期存在
→ Windows 检测不到 → 不弹。至 20:35 约 50 分钟零新增（背景率约 7 次/小时，显著低于背景，
**早期信号，非结论**）。可量化判据：次日全天根门户页新增访问应从 30-60 次/天 掉到接近
零；偶发个位数对应门户主动踢线后通道重登的窗口期，属正常恢复链路代价。

辅助开关（治标，用户自决）：Win11 设置 > 网络和 Internet > WLAN > STU 属性 >
「检测到需要登录时自动打开登录页」。

## 残留监视与未解

- `%TEMP%\edge-popup-watch.ps1/.log`（200ms 进程+会话+4038/4042）、`%TEMP%\proc-watch.ps1/.log`
  （WMI 0.5s 全进程创建，12h）继续值守；弹窗若再复发，proc-watch 日志按时刻可锁定发起者映像。
- 未解小谜：19:45:07 出现的后台 Edge 主进程 13012 无启动记录（疑 watcher 初始化窗口漏记，
  与弹窗无关）。
- 旧守护 19:41:29 退出原因不明（无 panic、无崩溃记录、api.json 同刻清理，疑手动）。
