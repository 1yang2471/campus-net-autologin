## 本轮新发现缺陷（均已修复）

1. **recordLog 时区缺陷**（我 0c091df 引入）：落文件行用 `time.Now()`（gomobile
   挂 UTC），行标 17:57:11 实为本地 01:57:11。修复：改用 `tzNow()`；红灯测试
   `TestRecordLogStampFollowsInjectedClock`（宿主上默认偏移 0 → 事件行应 ≈UTC，
   裸 time.Now 在东八区机器差 8h）守回归。
2. **beatWait 不感知 stop**（我 3d27527 引入的回归，测试运行中暴露）：Stop() 后
   beatLoop 要等满剩余兜底计时才退（测试 61s 超时 goroutine 栈为证），旧 tickLoop
   的 select 带 stop 分支无此问题。修复：`beatWait(stop, wake, floor)`；红灯
   `TestBeatWaitInterruptedByStop`。
