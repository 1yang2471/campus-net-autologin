## 状态→颜色+形状（颜色不得是唯一载体，规格 §13.2）

| 状态 | 颜色 | 形状 |
|---|---|---|
| online | accent 绿 | 实心圆 |
| offline / portal_down | warn 橙 | 圆环（空心） |
| rejected | danger 红 | 圆环+斜杠 |
| free_window / paused / starting | idle 灰 | 状态灯（环+心点，Python 守护同款） |

- **面板状态点颜色取回路 `s.color`，不抄本地词表**（rule #6 同源）：SVG 用
  `currentColor`，须设在元素 `color` 属性上（设 `fill` 属性无效，2026-11-08 实证渲染成白）。
- **诊断行显示物理源地址**（`s.v4_src`/`s.v6_src`）而非状态词——状态大卡已说一遍，
  行内重复即违反删除测试；源地址是加速器/TUN 下「从哪张网卡出去」的独有事实。
- **双读数（2026-11-18）**：状态卡在状态/详情下并列显示「认证：在线/离线/未知｜
  用户路径：通/不通/未知｜原因」。原因词表只在 api 包（`reason_label`），面板不自造；
  托盘 tooltip 只在用户路径 broken 时加「用户路径不通」，ok/未知不占长度。

## 字体（Windows 系统 UI 字体，零下载）

- 家族：Segoe UI（回退系统默认）
- 字号四档：22px 状态大字 / 14px 正文 / 12px meta；层级靠 400/600 两档字重
- 行高：正文 1.5；数字用 tabular-nums
- **表单控件强调色 = accent**（`accent-color: var(--accent)`）：浏览器默认蓝不在
  本调色板内（2026-11-08 de-slop 实证：复选框渲染成蓝）。

## 形状与间距

- 圆角：面板 12px，内层控件 8px（嵌套：内 = 外 − 内边距）；不做药丸
- 间距 4px 栅格：面板边距 24，分组间 20，组内 12；状态卡内边距 16
- 容器处理单一：浮起块只用底色，不加边框阴影
- 高级设置折叠区用原生 `details/summary`（summary 取 text-2，组间距 12），
  表单沿用同一 input/checkbox；不引入新色、阴影或动画
- 视图切换用文字 tab + 2px 下划线（选中 text、未选 text-2），不做药丸、
  不引入新色；状态页单屏，设置页可滚动
- 触屏（`pointer: coarse`）可点面 ≥44px；桌面鼠标密度不变。折叠开关
  `details summary` 原生 `min-height:0`，必须一并纳入 coarse 规则（否则
  高级设置在手机上点不开）
- 禁用态：`button:hover` 限定 `:not(:disabled)`，cursor 用 `not-allowed`；
  禁用按钮不得因 hover 点亮边框给出可点暗示
- 免认证时段行：两个 time 输入可伸缩（`flex: 1 1 108px; min-width: 0`），
  「删除」按钮 `flex: none; white-space: nowrap`——375px 窄屏下不得把
  两字标签挤成竖排（最小高度达标不等于文字可用）

## 动画

- 零装饰动画；状态切换即时换图标/文字；唯一过渡 = 面板窗口出现，120ms 淡入

## 文案

- 按钮写动作：「立即检测重连」「退出」；状态行直接说结论：「在线」「出口受限（观察：大众站 TLS 被重置…）」
- 禁止：感叹号、表情符号、营销词；错误信息带下一步动作
