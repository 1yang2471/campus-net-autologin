# 2026-11-11：流量能力升级（只读展示 + 一次性提醒）

> 触发：用户「产品能力的一个升级可以做」，并明确选了「连真弹通知一起做」。
> 技能：tdd（垂直切片 RED→GREEN）、unslop（polish mode）、grill-me（四个设计分支）。
> 范围经四轮问答收敛：**只读、零副作用**——不自动暂停、不断网、不改自动连。

## 1. 用户拍板的四个分支

| 分支 | 选择 |
|---|---|
| 升级范围 | 只读展示 + 阈值提醒；不做「预计用完时间」、不做「到阈值自动暂停」 |

最终确认又加了一条：**连真弹通知一起做**（Windows 托盘气泡 / Android 前台服务通知）。

## 2. 做了什么（TDD 垂直切片，逐条 RED→GREEN）

| 切片 | 行为 | 落点 |
|---|---|---|
| 1 | 带单位字符串归一成字节（`2.40006G`/`603.281M`/`4G`/`1.2 GB`/`512K`）；认不出返回「算不出」，裸数字无单位也判算不出 | `keeper/flux_usage.go` `ParseFluxBytes` |
| 2 | 用量视图 `used/quota/percent/has_percent/level/raw`；键名按别名优先级取（异校零回归），缺字段保留原文、百分比空，`用户名称` 不带出（凭据纪律） | `keeper.FluxUsage` |
| 3 | 阈值状态机：80%/90% 各发一次，同档连续观察不重复、回落重涨不重复，算不出百分比不提醒，阈值可配 | `keeper/flux_warn.go` |
| 4 | 10 分钟节流查询；查询失败保留上次读数；**一拍最多只打一次 userflux** | `keeper.Daemon.pollFlux` / `updateFluxView` |
| 5 | `Snapshot.Flux` 进 `/state`；compose 接线；ini `flux_poll_interval_sec` / `flux_warn_at` 可配 | `api.Snapshot` / `app/compose_api.go` / `app/config.go` |
| 通知 | 一次性越阈事件 → Windows 气泡（自建 `Shell_NotifyIconW` 独立 GUID 图标）、Android 前台服务独立 ID 通知 | `cmd/cnalw/flux_balloon_windows.go`、`FluxNotice.kt` |
| 面板 | 今日流量卡片（已用 / 额度 / 百分比 / 进度条），从 `s.flux` 渲染 | `panel.html`/`.css`/`.js` |

### 切片4 踩到并修好的真实回归

新轮询挂进 `Tick` 后，既有 `TestFluxProbeThrottledTo60s` 立刻报红：
「60s 内只允许 1 次 userflux，实际 2 次」。根因是**同一个 `FetchFlux` 缝被会话探针与
流量轮询各查一次**，会真给门户加倍压力。修法：两处共用一次读数——
`updateFluxView` 记 `fluxQueriedAt` + `fluxAt`，`pollFlux` 排在 `probeSession`
之后，本轮已查就复用；空表也算「查过」（否则下一拍又查）。新增
`TestFluxPollNeverAddsARequestOnSameTick` 钉住这条红线。

## 3. unslop 方向（polish mode）

现有面板已是深色石墨中性底、发丝边框、等宽数字、单一绿色 accent，**没有 slop 迹象**
（无渐变/发光/emoji/感叹号）。按协议不重做整页，只做有依据的最小改动：

- 产品：给校园网用户看「连没连上、今天用了多少」的守护面板。
- 性格：克制、准确、不打扰。世界：仪器/值班台（现有深色已契合）。
- 唯一亮点：新增的**流量进度条**——单一 accent，越阈才转 warn/danger。
- 签名细节：状态点（已有 `setGlyph`，不动）。
- 4px 栅格、短标签、无感叹号、hover 只变表面色；`prefers-reduced-motion` 下关过渡
  （a11y 验收当场抓到并修）。

## 4. 配置

```ini
[keeper]
flux_poll_interval_sec = 600   ; 默认 600（10 分钟）；0/非法回落默认
flux_warn_at = 80,90           ; 默认 80,90；非法（含 90,50 / >100）回落默认，不拦启动
```

## 5. 边界（明确不做 / 不宣称）

- **零副作用**：不自动暂停自动重连、不断网、不修改登录逻辑。误判最多是多一条通知。
- 「免认证时段是否不计流量」**未验证**：夜间隔夜额度口径需实测，本文不写成承诺。
- Windows 气泡用自建 `Shell_NotifyIconW`（systray 不导出气泡 API），**未经真机人工
  目视确认**——只在编译/vet/单元测试层验过；Android 通知同样只过了 JVM 单测，
  未装新 APK 目视。
- 未重跑 Mimosa 全量安全扫描；**不宣称项目安全**。
- 异校「字段名是校事实」：已用/额度只按已知别名取，取不到就原文照列，不猜。
